# Recursos visuais

`logo-pikpega.svg` é o símbolo de identidade usado nos metadados do projeto. As imagens ilustrativas das páginas são servidas através de Manus Storage para a pré-visualização do projeto. Para alojamento estático independente, descarregue os visuais finais para esta pasta, substitua os caminhos `/manus-storage/async-images/...` nos HTML por `img/nome-do-ficheiro.webp` e confirme que as imagens não são apresentadas como fotografias reais do acervo.
